# Extension Icons

To generate the required icons for the extension:

1. Open `generate-icons.html` in your web browser
2. Click "Download All Icons" or download each size individually
3. The following files will be downloaded:
   - `icon16.png` (16x16 - toolbar icon)
   - `icon48.png` (48x48 - extension management)
   - `icon128.png` (128x128 - Chrome Web Store)

4. Place all three PNG files in this `icons/` directory

Alternatively, you can use the `icon.svg` file and convert it to PNG at different sizes using an online tool or image editor like:
- https://cloudconvert.com/svg-to-png
- GIMP, Inkscape, or Photoshop

## Icon Sizes Required
- **16x16**: Displayed in the browser toolbar
- **48x48**: Used in the Extensions management page
- **128x128**: Used in the Chrome Web Store listing

The extension will not load without these icons!
